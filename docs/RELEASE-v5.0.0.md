# After Dark 5.0 — English Edition

**Pre-release** of the independent After Dark compatibility project.

## Changes

- English setup wizard, control panel, tray menus and settings dialogs.
- After Dark 5.0 product name and `5.0.0.0` file metadata.
- Original compact setup layout and classic interface.
- Updates over an existing installation preserve settings.
- Original module folder and registry names are retained for compatibility.

## Install or update

Download **AfterDark-5.0-Setup-English.exe** from the release assets.

Choose **Exit** from the existing After Dark tray icon and close previews before starting Setup. When updating, keep the existing installation folder. You do not need to uninstall first.

## Status

Package, catalog, rendering, file rollback and settings-model checks passed. Real installation, module playback and full-screen configuration still require testing on the destination computer. This release is marked **Pre-release** for that reason.
