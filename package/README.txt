AFTER DARK 5.0 — ENGLISH EDITION

Independent compatibility project. This is not an official Berkeley Systems release.
The 5.0 name identifies this project; the original modules keep their original formats.

INSTALL OR UPDATE
Choose Exit from the current After Dark tray icon and close all previews.
Run AfterDark-5.0-Setup-English.exe. To update, keep the existing installation folder.
Your module settings and unrelated files are preserved. No prior uninstall is required.

CONTROL PANEL
Double-click the tray icon to open the panel.
Help displays the original module documentation.
Setup opens a full-screen preview with a floating settings panel.
Settings take effect by automatically reloading the preview engine.
Stop ends the configuration preview. A key pressed outside its controls also exits it.
More options provides fish, creature or music settings when supported.
OK saves and closes the panel; Apply saves; Cancel discards pending panel edits.
Closing the panel keeps the tray application running. Exit closes the tray application.
Windows continues to start the registered screensaver even when the tray app is closed.

The user interface and our error messages are in English. Windows system dialogs use
the language configured in Windows. Original modules retain their original content.

UNINSTALL
Choose Exit, then uninstall After Dark 5.0 from Windows Apps, or run Uninstall.exe
/uninstall in the installation folder. Program-owned files and empty folders are removed.
Settings and unrelated files are kept. The previous Windows screensaver settings are
restored when After Dark is still the selected screensaver.

COMPATIBILITY
The original module folder and registry names still mention After Dark 4.0. This is
intentional and allows the original engine to read saved preferences.
The compact classic interface, Windows registration, modules and engine are unchanged
apart from English interface text, product branding and the uninstaller filename.

VALIDATION
The installer, panel, advanced dialogs and floating controls were rendered and inspected.
Package extraction, module catalog, file updates and rollback, and the Windows settings
integration model have been checked. Actual elevated installation and live animation
still require a test on the destination computer. No installed preferences were changed
while building this edition.
